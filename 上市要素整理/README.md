# 上市要素整理

把**任意排版**的债券上市要素文本，整理成固定模版。纯本地、零第三方依赖。

## 模版

```
日期+0 上市要素：
代码 名称  券面  票面  净价100 XX出给YY  发XX请求
XX信息
YY信息
```

回填后的实际样子（样本）：

```
1029+0 上市要素：
102683905.IB  26上饶产投MTN001  券面 100  票面 2.05%  净价 100  江城银行出给龙头证券  发江城银行请求
江城银行 刘如烟 QT 2555555555
龙头证券 陈默 QT 2555555556
```

规则：

- `XX出给YY`：XX 是卖方，YY 是买方。
- `发XX请求`：XX **等于卖方**（同一机构名出现两处）。
- 联系人顺序跟随买卖顺序：卖方在前，买方在后。
- 字段之间两个空格，标签与值之间一个空格。

## 为什么不是「按位置切」

输入来源不固定：可能是聊天记录、公告、Excel 复制出来的零散字段，顺序、标点、全角半角都可能乱。所以解析走的是：

1. **归一化**：全角转半角、日期归一、标点转空格、锚点词分隔。
2. **特征分类**：代码、日期、利率、号码、机构、债券名各自按形态识别。
3. **锚点组装**：`出给/卖给/→` 定买卖双方；`发X请求` 校验请求对象。
4. **交叉校验**：卖方名在三个位置不一致时标黄，不静默修正。

改识别规则只改 `listing/features.py`（标量特征表），不要把正则散到别处。

## 跑起来

```powershell
py -3.11 app.py                 # 默认 127.0.0.1:8513
py -3.11 app.py --port 8600 --no-browser
```

也可以从「固收工作台」里点「上市要素整理」启动。

## 随机测试文本

```powershell
py -3.11 tools/gen_mock.py                 # 1 条
py -3.11 tools/gen_mock.py -n 5            # 5 条
py -3.11 tools/gen_mock.py --copy          # 顺便放剪贴板
py -3.11 tools/gen_mock.py --layout dense  # 指定排版
```

排版有五种：`labeled`（带标签多行）、`shuffled`（单行乱序）、`chatty`（夹聊天废话）、`dense`（全挤一行）、`fullwidth`（全角标点）。每次内容随机，但**八个变量一个不少**。

页面右上角「随机示例」按钮等价于 `gen_mock.py`。

## 目录

```
上市要素整理/
├── app.py                 # 入口（标准库 http.server）
├── listing/
│   ├── normalize.py       # 归一化
│   ├── features.py        # 标量特征表（改规则先改这里）
│   ├── extract.py         # 分类 + 锚点组装 + 校验
│   ├── render.py          # 模版渲染
│   ├── mock.py            # 随机语料
│   └── web/               # 单页前端（无框架、无 CDN）
├── tools/gen_mock.py      # 随机测试文本 CLI
└── tests/                 # unittest（解析 + 服务端）
```

## 测试

```powershell
py -3.11 -m unittest discover -v
```

覆盖：用户样本精确比对、五种排版 × 12 个种子的随机语料、全角/中文日期、聊天噪音、bp 利率、服务端接口。

## 已知边界

- 一次处理一只债；多只债请分次粘贴。
- 债券代码支持 6-9 位 + `.IB/.SH/.SZ/.BJ`；无后缀时保留原样并提示。
- 8-9 位号码靠上下文（是否邻近渠道词/人名）判断，极短号码可能被当成债券代码。
- 机构名靠后缀（银行/证券/信托/基金/资管…）识别；没有后缀的简称需要手动补。
