# 境内债制表工具（专项工作区）

**目标**：把地方债 / 信用债原始数据表一键转换为**分品种的标准表格**——地方债 11 列（源表为 35 列招标表）、信用债 11 列新表头（源表为 52 列真实导出表，两种源表完全不同）；地方债、信用债制表结果旁均可**一键生成"待发行"播报文本**（"今日/本周"头行可切换）。Python 实现，**可视化、易操作、跨平台**（Windows / macOS / Linux）。

## 快速开始

### 1. 零终端方案（推荐）：双击启动

- **Windows**：双击项目根目录的 **[启动.bat](../境内债制表工具/启动.bat)**——弹出**常开进度窗口**，逐步显示当前进展：`[1/5] 检测 Python → [2/5] 准备虚拟环境 → [3/5] 检测依赖 → [4/5] 启动网页界面 → [5/5] 运行中`
- **macOS**：双击项目根目录的 **[启动.command](../境内债制表工具/启动.command)**——脚本已内置**自愈**（成功运行一次即自动清除隔离标记、补齐可执行权限，之后双击永久正常）；首次双击若被拦，任选下方一种一次性方法即可

双击后自动完成：检测/创建虚拟环境 `.venv` → 首次运行自动安装依赖 → 启动网页界面 → 浏览器自动打开 `http://localhost:8501`。**之后每次使用仍然只需双击**，已装好的环境会自动跳过安装步骤。

> **macOS 双击被拦怎么办**（提示"无法验证的开发者"或双击无反应）：这是 macOS 对所有外来脚本的通用安全策略——经浏览器/微信/压缩包传来的文件带**隔离标记**（Gatekeeper），从 Windows 拷来还会**丢失可执行权限**；被拦时脚本自身没有机会运行，因此没有任何脚本能做到"完全免一次确认"。本工具的 `启动.command` 已内置**自愈**：只要成功运行一次，就自动清除整个项目的隔离标记并补齐权限，**之后双击永久正常**。一次性运行任选其一：
>
> 1. **终端法（100% 有效，约 10 秒）**：打开「终端」→ 输入 `bash `（注意有个空格）→ 把 `启动.command` 拖进窗口 → 回车。工具照常启动，并自动完成自愈。
> 2. **系统设置法**：先双击一次（会弹出拦截提示）→ 打开「系统设置 → 隐私与安全性」→ 点「仍要打开」→ 再双击即正常运行并自愈。
> 3. **右键打开法**（旧版 macOS 对脚本有效）：右键 `启动.command` → 打开 → 再点"打开"。
>
> 另：用 U 盘/移动硬盘/局域网共享直接拷贝的文件不带隔离标记，通常双击直接就能运行（首次运行同样会自愈补权限）。

### 2. 手动方式（可选，Python 3.9+）

正常环境手动安装依赖：

```powershell
python -m pip install -r scripts/requirements.txt
```

受限环境（pip 安装被拦截时）的备用方式——下载 wheel 解压到 `.pydeps`：

```powershell
python scripts/bootstrap_deps.py
```

### 3. 手动启动的两种用法

**命令行批量**（把原始表放进 `data/原始数据/` 后一条命令）：

```powershell
python scripts/transform.py --input data/原始数据
```

**可视化界面**（浏览器操作：上传 → 核对债种 → 一键制表 → 预览 + 下载）：

```powershell
python -m streamlit run scripts/app.py
```

> 若依赖装在 `.pydeps`（bootstrap 方式），运行前先执行 `$env:PYTHONPATH=".pydeps"`（PowerShell）或 `set PYTHONPATH=.pydeps`（CMD）。
