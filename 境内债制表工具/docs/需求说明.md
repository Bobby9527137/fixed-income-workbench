# 需求说明 — 境内债制表工具

> 版本 v1.2（2026-10-09 真实数据联调修正：地区短名解析适配真实简称 / 标黄不再置顶改按发行日排序 / 债种识别加别名 / 上传内存直读）｜状态：映射按品种分套落定并经真实文件验证（地方债 35 列招标表→11 列、信用债 52 列导出表→11 列）· 地方债行标黄（不置顶）＋按发行日排序已实现 · 两债"待发行"播报文本已实现 · 界面已定（Streamlit）· 输出已定（两个独立文件）

## 1. 项目目标

开发一个以 Python 为基础的制表工具，将两种境内债（**地方债**、**信用债**）的原始数据表一键转换为统一格式的目标表。

基本要求：
- **可视化**：图形操作界面，转换前后的表格可预览
- **易操作**：选择文件 → 一键生成，非技术人员可独立使用
- **运行环境**：纯 Python 方案，macOS 开箱即用，不依赖平台专用组件

## 3. 目标表格（输出）

**分品种两套目标表头**（2026-10-09 确认），各 11 列：

- **地方债**：发行日、发行时间、招标系统、债券代码、债券简称、性质、专项、期限、发行量(亿)、缴款日、上市日
- **信用债**（新表头）：截标时间、发行日、债券简称、期限、发行量(亿)、申购区间、主/债评级、发行人、YY评级、缴款日、公告日

与原表的逐列对应关系详见 [表头对照表.md](../境内债制表工具/docs/表头对照表.md)，机器可读版本见 [表头映射.json](../境内债制表工具/config/表头映射.json)（按品种分节配置）。

## 4. 功能需求

1. 在界面中选择（或拖入）原始 Excel 文件
2. 自动读取 → 按 `config/表头映射.json` 取列 → 清洗格式 → 生成标准表
3. 转换前后的表格可在界面中预览核对
4. 结果输出为两个独立 .xlsx（地方债、信用债各一个；带表头加粗、边框、列宽自适应等基本排版）
5. 全过程有进度/成功/失败提示，出错时给出可读原因（如缺列、表头改名）
6. **双击即用**（2026-10-09 增补）：根目录提供 `启动.command`，双击后自动检测/创建虚拟环境、安装依赖、启动界面并自动打开浏览器，非技术人员全程无需在终端输入命令；启动脚本带**自愈**（成功运行一次即自动清除隔离标记、补齐可执行权限，之后双击永久正常）；虚拟环境损坏时自动重建
7. **一键制作文本**（2026-10-09 新增，同日按真实样例修正）：两债制表结果旁各自一键生成"待发行"播报文本，按发行日升序分组（组头 M/D 不补零，组间空行），头行 `*本周/今日 + 债种 + 待发行*【XX亿】`（**"今日/本周"网页内一键切换**）。**地方债**：同日同地区**合并为一行**——`地区短名+当日合计(4 位小数)亿（期限集合）`，地区短名不带行政区划后缀（江西、宁波），期限去重后按数值升序空格分隔（`5Y 7Y 10Y`）。**商金债（信用债）**：每券一行——`债券简称 金额亿（期限）`（如 `26重庆银行债01 20亿（3Y）`），金额去尾零。文本与表格均按发行日升序；网页内一键复制或下载 .txt。**地区短名解析已适配真实简称**（2026-10-09 联调确认）：'26内蒙古27'（无"债"字）→ 内蒙古、'26青岛81' → 青岛、'26广东债40(续发)' → 广东（**续发行并入本地区，不单列**）

## 5. 数据清洗规则（大部分已实现，并经模拟数据端到端验证）

- **债券代码按文本读取**，保留前导零（防止 019742 被 Excel 变成 19742）
- 日期列（发行日 / 缴款日 / 上市日）统一为 YYYY-MM-DD（兼容 Excel 日期序列号、2024/5/6、2024年5月6日 等写法）
- 时间列（发行时间）为招标时间段（如 9:30-10:10、15:00-15:40），逐时间点补零对齐（9:30-10:10 → 09:30-10:10）
- 发行量(亿) 保持数值，统一保留 2 位小数
- 期限列已按用户口径确认（2026-10-09）：年用字母 Y 表示——'5Y' 保持、'10年' → '10Y'、纯数字 '3' → '3Y'、'5+N年' → '5+NY'
- 地方债字段口径（2026-10-09 确认）：招标系统取值一般为"中央国债登记结算有限责任公司"（直接带入）；性质 ∈ {新增, 置换, 再融资}；专项（原表"类型"）∈ {专项, 一般}；债券代码为"7位.IB"格式；债券简称为"年份+地方+债+数字"（如 26江西债47）；发行日等日期格式经确认无误
- 信用债字段口径（2026-10-09 确认，基于 52 列真实导出表）：**截标时间**直取源表"截标时间"列并归一为"月-日 时:分"（不带年份），'2026-09-24 17:00' → '09-24 17:00'、'9-25 17:30' → '09-25 17:30'；**发行日** ← 发行起始日；**发行量(亿)** = 实际发行(亿) 优先、空则取计划发行(亿)；**申购区间** ← 投标区间(%) 直取（有则有，没有则空，不用占位）；**主/债评级** = 主体评级＋"/"＋债项评级 合成（都在 → 'AA+/AA+'；债项空 → 'AAA/'）；**发行人**、**公告日**直取；**YY评级** ← YY评分（区别于同表 yy定价）
- 去除全空行；输出列顺序严格按目标表头排列
- **地方债行标黄与排序**（2026-10-09 v0.10 修订，真实联调反馈）：债券简称含"贵州/陕西/江西/西藏"的行**整行标黄**（黄色填充），但**不再置顶**——整表按**发行日升序**排列（stable：同日保持源表顺序，空发行日排最后；排序列在配置 `row_order` 中可调）；匹配列、关键词与颜色在配置 `row_highlight` 中可调；信用债无此规则、保持源表顺序
