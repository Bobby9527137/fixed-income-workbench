# 固收工作台 · 交接说明（维护者）

> 目标：拿到这个目录后，能在 10 分钟内知道**东西在哪、怎么跑、怎么加工具、怎么验证**。

## 1. 这是什么

一个纯本地的启动台，把四个工具收进同一个入口：

| 工具 | 目录 | 类型 | 默认端口 |
|---|---|---|---|
| 境内债制表 | `境内债制表工具/` | Streamlit | 8511 |
| 投标簿记提取 | `bidbook_tool/` | FastAPI + 自定义页 | 8765 |
| WACC 批量计算 | `wacc-tool/` | Streamlit | 8512 |
| 上市要素整理 | `上市要素整理/` | 标准库 http.server | 8513 |
| 债券计算器 | `固收工具箱/apps/` | 标准库 + openpyxl | 8514 |
| 回购/资金计算器 | `固收工具箱/apps/` | 标准库 + openpyxl | 8515 |
| 现金流/付息日历 | `固收工具箱/apps/` | 标准库 + openpyxl | 8516 |
| 组合风险快照 | `固收工具箱/apps/` | 标准库 + openpyxl | 8517 |
| 国债期货基差 | `固收工具箱/apps/` | 标准库 + openpyxl | 8518 |
| 投标/中标统计 | `固收工具箱/apps/` | 标准库 + openpyxl | 8519 |
| 交易要素提取 | `固收工具箱/apps/` | 标准库 + openpyxl | 8520 |

工作台本体只做四件事：**启动/停止子进程、单实例、环境自举、打开页面**。它不碰十一个工具的业务代码，也不打通它们之间的数据。

- 只监听 `127.0.0.1`，校验 `Host` / `Origin`。
- 运行期零网络：依赖来自本地 wheelhouse，Python 来自包内归档。
- 工作台本体只用 Python 标准库；前端无框架、无 CDN。

## 3. 一次启动发生了什么

```
双击 启动工作台.command
  → bash：xattr / chmod 自愈
  → 预解压 runtime/python/*.tar.gz
  → 验证 python ≥ 3.10
  → exec python start.py
       → load_config(tools.json)
       → acquire_launch_lock（并发双击只放一个）
       → find_running（lock + /api/ping；命中就开浏览器返回）
       → pick_free_port（8787 起顺延 20 个）
       → Bootstrapper / ToolManager / adopt_orphans()
       → 注册 atexit 与 SIGTERM / SIGHUP
       → 后台 ensure_all_async()（建 venv + 装 wheel）
       → 打开工作台页面
```

浏览器每 2 秒请求 `/api/state` 刷新卡片。点「启动」→ `POST /api/tools/<id>/start` → 起子进程 → 轮询健康地址 → `running`。

**归属模型**：`self`（本次启动）/ `orphan`（上次残留，可停）/ `external`（不是我们起的，拒绝停止）。

## 4. `tools.json` 配置契约

```jsonc
{
  "version": 1,
  "workbench": { "port": 8787 },
  "platform": {
    "darwin": { "pythonArchive": "runtime/python/cpython-...tar.gz" }
  },
  "environments": {
    "streamlit": {
      "requirements": { "darwin": "requirements/streamlit-mac.txt" },
      "wheelhouse":  { "darwin": "runtime/wheels/macos-arm64-cp312" },
      "probe": ["streamlit", "pandas", "openpyxl"]
    }
  },
  "tools": [
    {
      "id": "bondtable",
      "name": "境内债制表",
      "desc": "…",
      "root": "./境内债制表工具",
      "kind": "streamlit",
      "entry": "scripts/app.py",
      "args": ["--port", "{port}"],
      "environment": "streamlit",
      "port": 8511,
      "healthPath": "/_stcore/health",
      "dirs": { "输出": "data/输出" }
    }
  ]
}
```

约定：

- `kind=streamlit` 时由工作台拼 `python -m streamlit run <entry> --server.address 127.0.0.1 --server.port … --server.headless true`。
- `kind=python-entry` 时直接 `python <entry> [args]`。
- `healthPath` 必须是真实可返回 200 的路径；bidbook 与 listing 没有专用健康路由，用 `/`。
- `dirs` 里 key 含「输出」的目录用于「最近产物」。

## 5. 新增一个工具

假设新工具目录叫 `new-tool/`，入口 `app.py`（FastAPI）：

1. **放目录**：完整放进本目录，不改它的业务代码。
2. **建环境**（依赖与现有环境不同时）：
   - 新建 `requirements/newtool-mac.txt`；
   - 在 `tools.json.environments` 加一条，`probe` 填能验证依赖是否装好的模块名。
   - 把对应 wheel 放进 `runtime/wheels/macos-arm64-cp312/`（构建期操作，见私有构建仓库）。
3. **登记工具**：在 `tools.json.tools` 加一条。
4. **测试**：
   - `tests/` 加启动/停止用例（可复用 `tests/fixtures/dummy_tool.py` 的模式）；
   - `scripts/acceptance/` 加该工具的输入矩阵。
5. **前端不用改**：卡片由 `/api/state` 驱动。

> 不要：把依赖装进工具自己的 `.venv`、在运行期 pip install、在首次运行时下载模型或数据。

## 5.2 自检与标准报告

- 每个工具：`GET /api/selfcheck?fix=1`，检查 Python / openpyxl / 报告目录 / 字段定义 / 示例计算。
- 工作台：`GET /api/selfcheck?fix=1`，检查配置、工具目录、环境、锁、端口。
- 能修的：创建目录、清理死 pid 锁、清理超时启动锁、剔除残留 pid 记录。
- 修不了的：生成 Markdown 报告。
  - 工具报告：`~/固收工作台报告/<tool>-bug-*.md`
  - 工作台报告：`<runtime>/reports/workbench-selfcheck-*.md`
- 报告只在本机，不自动发送；用户确认后再转发。

## 7. 发布包怎么来的

Release 里的 zip = **本仓库全部内容 + `runtime/`**（内置 Python 与 wheelhouse）。

```
固收工作台-macOS-arm64-<日期>.zip
└── 固收工作台/
    ├── <本仓库全部源码与文档>
    └── runtime/
        ├── python/cpython-...tar.gz
        └── wheels/macos-arm64-cp312/
```

打包脚本在私有构建仓库；发布前确认包内只有 macOS 内容。

## 9. 常见故障

| 现象 | 先看 | 处理 |
|---|---|---|
| 双击没反应 | `.command` 是否有执行位 / 被隔离 | 右键→打开；或 `bash 启动工作台.command` |
| 页面打不开 | `runtime/logs/start.log` | 先跑 `诊断报告.command` |
| 端口被占 | 卡片显示的实际端口 | 自动顺延；占满会明确报错 |
| 卡片显示「上次残留」 | `pids.json` | 点「停止」清理 |
| 环境想重来 | `runtime/envs/<id>` | 删掉后重启，或页面点「重建」 |
| 想彻底重置 | `runtime/` | 退出工作台后整目录删除 |

## 10. 不可违反的约定

- 运行期**零网络**；依赖只从本地 wheelhouse 安装，Python 来自包内。
- 只绑 `127.0.0.1`；`Host` / `Origin` 校验不能删。
- **不改**四个工具的业务代码；只用子进程调用。
- 所有文件读写显式 `encoding="utf-8"`；子进程参数用 list，不拼 shell。
- 工作台本体只用标准库；前端不引 CDN / 网络字体。
- 端口：8787 / 8511 / 8765 / 8512 / 8513 / 8514–8520，被占顺延最多 20 个。
- 发行包只保留 macOS 内容。

## 11. 已知限制

1. **仅 Apple Silicon**：内置 Python 与 wheelhouse 都是 arm64；Intel Mac 需自行替换。
2. **投标簿记 OCR 的边框检测**：字号 ≥26px 且简称较长时，汉字竖笔可能被当成表格竖线，导致整表 0 行。临时绕法：截图字号 ≤22px，或走窗口 2 补数。
3. **WACC 的 `analyze_selection`** 对缺键会 `KeyError`（界面不会触发，因为控件总是全量）。
4. **工作台不内嵌工具页面**：工具在独立标签页打开，避免 iframe 兼容问题。
5. **上市要素整理**：一次一只债；代码无后缀时保留原样并提示；无机构后缀的简称需手动补。
