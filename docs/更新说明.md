# 更新说明（增量更新包）

每个 Release 提供两个资产：

| 资产 | 用途 | 大小 |
|---|---|---|
| `fixed-income-workbench-macOS-arm64-vX.Y.Z.zip` | 完整包，首次安装用 | 约 201 MB |
| `fixed-income-workbench-update-vX.Y.Z.zip` | 增量更新，覆盖到已有目录 | 几 KB 到几百 KB |

## 升级步骤（已经装过旧版）

1. **退出工作台**（关闭终端窗口）。
2. 到 Releases 下载对应版本的 `...update-vX.Y.Z.zip`。
3. 解压。
4. 把解压出来的文件拖进原来的工作台文件夹，选择「替换 / 合并」。
5. 重新双击 `启动工作台.command`。

命令行方式更稳（推荐）：

```bash
cd /path/to/固收工作台
unzip -o ~/Downloads/fixed-income-workbench-update-v0.1.3.zip
```

### 说明

- 更新包里**不含** `runtime/`，内置 Python 与依赖原样保留，不需要重新下载。
- 包内有 `更新说明.txt` 和 `update-manifest.json`（版本、文件清单、SHA256）。
- 更新包没有顶层目录，解压后直接覆盖到工作台根目录即可。
- 如果更新后异常，重新下载完整包覆盖即可。

## 维护者：生成更新包

```bash
python3 scripts/make_update.py \
  --base v0.1.2 \
  --target HEAD \
  --version 0.1.3 \
  --base-version 0.1.2 \
  --out dist/fixed-income-workbench-update-v0.1.3.zip
```

规则：

- 只打包 `base..target` 之间改动过的文件。
- 文件内容从**目标 commit** 读取（`git show <target>:<path>`），不读工作区，避免把未提交的改动混进去。
- 自动生成 `更新说明.txt` 与 `update-manifest.json`。
- 发布时**同时上传完整包和 update 包**，两个资产都挂在同一个 Release 下。
- 如果本次有文件删除，脚本会警告；删除操作需要手动处理（或在更新说明里写明）。
