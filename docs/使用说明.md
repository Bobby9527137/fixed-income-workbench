# 固收工作台 · 使用说明（macOS）

一个入口，管十二个工具：常用的是 **境内债制表**、**投标簿记提取**、**报价要素生成**、**WACC 批量计算**、**上市要素整理**、**交易要素提取**，其余计算/整理工具收在右侧「更多工具」里。
全部在本机运行，**不需要联网**，也不上传任何数据。

---

## 一、第一次打开（只需做一次）

### 1. 解压到哪里

把 zip 解压到 **桌面** 或 **「应用程序」文件夹** 这类本地目录。

- 不要放在 iCloud Drive、OneDrive、坚果云等同步盘里（同步会拖慢启动，还可能导致文件被锁）。
- 路径里可以有中文和空格，工作台已适配。

### 2. 首次双击被拦下是正常的

macOS 对从网上下载的脚本会拦一次。按下面任一种方式打开：

**方式 A（推荐）**
1. 在 `启动工作台.command` 上**右键**（或按住 Control 点按）；
2. 选 **「打开」**；
3. 弹窗里再点 **「打开」**。

**方式 B（方式 A 没反应时）**
1. 双击一次 `启动工作台.command`，出现「无法打开」提示后点「完成」；
2. 打开 **系统设置 → 隐私与安全性**，向下找到「已阻止使用 启动工作台.command」；
3. 点 **「仍要打开」**，输入开机密码。

**方式 C（以上都不行时）**
打开「终端」，输入下面一行并回车（把路径换成你的解压位置）：

```bash
bash ~/Desktop/固收工作台/启动工作台.command
```

> 说明：以上操作只需做一次。之后直接双击即可。

### 3. 第一次启动会慢一些

第一次启动会自动完成四件事（全程离线，不下载任何东西）：

1. 解压包内自带的 Python；
2. 建「制表/WACC」运行环境；
3. 建「簿记」运行环境；
4. 启动工作台页面。

大约 3–8 分钟（取决于机器）。**过程中请不要关闭终端窗口**，页面左上角会显示进度。

## 二、日常使用

1. 双击 `启动工作台.command`；
2. 浏览器会自动打开 `http://127.0.0.1:8787`（没自动打开就手动输入这个地址）；
3. 首次运行成功后，**桌面会自动出现一个「固收工作台.command」快捷方式**，以后直接双击它即可（删掉不影响使用；不想让它生成可设 `WB_NO_DESKTOP_SHORTCUT=1`）；
4. 左侧六张常用工具卡片，点「启动」等状态变绿；点「打开」在浏览器**新标签页**里使用工具；
   - 右侧上半「运行中」集中显示已启动的工具，下半「更多工具」收纳其余较少用的计算/整理工具，直接点「启动」即可；
   - 顶部可「全部启动 / 全部停止」；卡片上的「日志」直接看运行日志，「目录」在 Finder 中打开输出目录；
   - 页脚「最近产物」按工具分组，点文件名会在 Finder 中定位；
5. 工作台与十二个工具统一使用**浅色/白底**界面；
6. 用完点右上角 **「退出工作台」**，或直接关掉终端窗口。

**再次双击不会开第二个工作台**：如果已经在运行，只会把已有页面打开。

### 端口

| 工具 | 默认端口 |
|---|---|
| 工作台 | 8787 |
| 境内债制表 | 8511 |
| 投标簿记提取 | 8765 |
| 报价要素生成 | 8766 |
| WACC 批量计算 | 8512 |
| 上市要素整理 | 8513 |

端口被占用时会自动顺延（最多往后找 20 个），卡片上**始终显示实际端口**。

## 三、常见问题

### 双击没反应 / 一闪而过

1. 确认是按「第一次打开」里的方式 A/B/C 打开的；
2. 如果是从压缩包直接双击（没有先解压），请先完整解压；
3. 仍然不行：打开「终端」，`cd` 到解压目录后执行
   `bash 启动工作台.command`，把窗口里的报错截图。

### 页面打不开（浏览器显示无法连接）

1. 看终端窗口是否还在、有没有报错；
2. 稍等 10–30 秒（首次启动要装环境）；
3. 在浏览器手动访问 `http://127.0.0.1:8787`；
4. 仍然不行：双击 `诊断报告.command`，把生成的 `诊断报告.txt` 发给维护者。

### 卡片一直「启动中」或显示红色错误

1. 点卡片上的「查看日志」，或双击 `诊断报告.command`；
2. 点卡片上的「停止」再「启动」重试；
3. 反复失败时，退出工作台，删除下面这个目录后重新双击（会离线重建，约 3–8 分钟）：

   ```
   ~/Library/Application Support/固收工作台/runtime/envs
   ```

4. Windows 上如果错误里出现 `No pyvenv.cfg file` / 退出码 `106`，说明 Python 是
   Microsoft Store 版（路径含 `WindowsApps`），它会把 `%LOCALAPPDATA%` 重定向进
   包私有目录。工作台会自动改用 `%USERPROFILE%\固收工作台\runtime` 存放环境；
   若仍失败，手动设置环境变量后重试：

   ```bat
   set WB_RUNTIME_DIR=%USERPROFILE%\固收工作台\runtime
   ```

### 提示端口被占用

工作台会自动换端口，以卡片显示为准。如果所有端口都被占，关掉占用端口的程序再重试。

### 上次异常退出，卡片显示「上次残留」

说明上次没正常退出，工具进程还在。点该卡片的 **「停止」** 即可清理，不会影响其他工具。

### 想彻底卸载

退出工作台后，删除解压出来的文件夹，以及：

```
~/Library/Application Support/固收工作台
```

## 四、诊断报告怎么发

双击 `诊断报告.command`，会在同目录生成 `诊断报告.txt`。
把它（或终端窗口截图）发给维护者即可；报告只包含本机路径、版本、端口、日志尾部，不含业务数据。

## 五、Mac 人工验收清单（交付前请在 Mac 上逐条确认）

> 本包在 Windows 上已完成自动化与全流程验证；以下 8 条**必须在 Mac 上人工确认**。

1. [ ] 解压到桌面，**断网**，右键→打开，5 分钟内看到工作台页面；
2. [ ] 左侧六张常用卡片都能启动，状态变绿，端口显示 8511 / 8765 / 8766 / 8512（或顺延值）；
3. [ ] 十二个工具在**独立标签页**里都能正常上传/下载/复制，且页面为白底；
4. [ ] 停掉一个，其他工具不受影响；运行中的工具会出现在右侧「运行中」，停止后次级工具回到「更多工具」；
5. [ ] 关掉终端窗口后 10 秒内，终端执行
      `lsof -i :8511 -i :8512 -i :8765 -i :8766` 无输出；
6. [ ] 第二次双击不再起第二个工作台，已运行工具显示「运行中」；
7. [ ] 手动占用 8511（例如 `python3 -m http.server 8511`）后启动制表，自动换端口且页面能打开；
8. [ ] 删除 `~/Library/Application Support/固收工作台/runtime` 后重新双击，能离线自愈重建。

另外建议：全程打开「活动监视器 → 网络」，确认工作台没有任何对外连接。
