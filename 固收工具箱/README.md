# 固收工具箱

七个本地小工具，共享一套计算、校验、自检和页面框架。全部离线运行，只监听 `127.0.0.1`。

| 工具 | 端口 | 输入 | 输出 |
|---|---:|---|---|
| 债券计算器 | 8514 | 单券条款、收益率或净价 | 净价/全价、应计、YTM、久期、凸性、DV01、持有期情景、现金流 |
| 回购/资金计算器 | 8515 | 金额、利率、起止日、费用、质押率 | 到期金额、实际年化成本、质押券、杠杆 |
| 现金流/付息日历 | 8516 | 持仓表（Excel 可导入） | 未来付息/兑付明细、年度汇总 |
| 组合风险快照 | 8517 | 持仓市值、久期、评级、行业 | 加权久期、总 DV01、评级/行业分布、±利率情景 |
| 国债期货基差 | 8518 | CTD 价格、CF、期货价、资金利率 | 基差、净基差、IRR、期货 DV01、对冲手数 |
| 投标/中标统计 | 8519 | 投标明细 | 按债券汇总的投标量、加权利率、中标率 |
| 交易要素提取 | 8520 | 交易聊天文本 | 结构化交易台账 + Excel |

## 运行

工作台里点对应卡片即可。单独运行：

```bash
python3 apps/bond_calculator.py --port 8514
python3 apps/repo_calculator.py --port 8515
# ...
```

只依赖 Python 标准库 + `openpyxl`；没有 pandas、没有网络请求。

## 每个工具都有

- **随机示例**：点一下生成一组真实感数据并自动跑完，直接看输出是否正常；
- **自检**：检查 Python 版本、openpyxl、报告目录、字段定义、示例能否计算；
- **Excel 导入/导出**：表格类工具可导入 `.xlsx` / `.csv`，结果可导出 Excel；
- **标准 bug 报告**：自检或运行出错时，在本机生成 Markdown 报告，先给你看，不自动发送。

报告默认在 `~/固收工作台报告/`，也可以用环境变量 `FI_REPORT_DIR` 改目录。

```
├── apps/                  # 七个入口，每个都很薄

│   ├── excel.py           # xlsx/csv 读写
│   ├── selfcheck.py       # 自检 + 标准报告

│   └── web/               # 共用单页前端
├── tests/                 # 债券数学 / 七个工具 / 服务端 / 报告
└── docs/
```

## 约定

- 金额单位默认「万元」，价格按每 100 元面值；
- 日期统一 `YYYY-MM-DD`；
- 收益率/票面/利率输入百分数（如 `2.35` 表示 2.35%）；
- 所有计算只在本机，不联网、不上传数据。
