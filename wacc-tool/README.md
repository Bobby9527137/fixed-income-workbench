# WACC 批量计算

一个双击就能用的加权平均资本成本（WACC）批量计算工具：Python + 网页界面，上传表格或手动录入，批量算出结果并导出 CSV / Excel。

## 启动（macOS）

1. 把整个目录放到 Mac 上（桌面、文稿都行；路径里尽量不要有空格）。
2. **首次使用**：在 Finder 里 **右键** `macOS/启动WACC工具.command` → **打开** → 弹窗里再点 **打开**。
3. **之后每次**：直接双击 `macOS/启动WACC工具.command`，几秒内浏览器自动打开。

> 首次运行会在后台自动创建虚拟环境并安装依赖（约 1–3 分钟），全程无需操作。
> 关闭弹出的终端窗口即等于关闭工具。

## 两种用法

### 模式一：上传表格批量计算

1. 上传 `.xlsx` / `.xls` / `.csv`。
2. 多张表时下拉选表；表头行会自动识别，不对就改「表头所在行」。
3. 核对读到的行列数，必要时用「从第几行开始 / 算到第几行结束」圈定范围。
4. 点「批量计算 WACC」，查看结果并导出。

### 模式二：手动录入

按界面提示填权益、负债、税率、无风险利率、Beta、风险溢价等参数，逐行计算或批量计算。

## 随机示例

左侧模式选「模式三：随机示例（自动生成）」，会随机生成 6–10 组参数（覆盖直接给 Re、CAPM、只给 D/E 三种路径），自动计算并显示结果。点「🎲 重新生成」换一组。

实现见 `random_sample.py`，回归测试 `tests/test_random_sample.py`。

## 已知限制

- `analyze_selection` 对缺键会抛 `KeyError`；界面控件总是全量，正常使用不会触发。调用方需传全 9 个键。
- 计算只在本机完成，不联网。
